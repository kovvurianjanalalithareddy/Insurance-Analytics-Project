# 📊 Insurance Analytics Project
End-to-End Data Analytics Project | SQL | Excel | Power BI | Tableau | Power Query

## Overview

This repository presents an end-to-end Insurance Analytics project developed using SQL, Microsoft Excel, Power Query, Power BI, and Tableau. The project demonstrates the complete data analytics lifecycle, from data cleaning and transformation to analysis, visualization, and business intelligence reporting.

The objective is to convert raw insurance data into meaningful business insights by developing interactive dashboards and KPI reports that support data-driven decision-making.

## Business Objectives

- Analyze insurance policy performance
- Monitor claims and revenue trends
- Evaluate branch performance
- Track key business KPIs
- Generate business insights through interactive dashboards
